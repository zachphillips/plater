How we work

Two people, one project at a time, start to finish. We write the HTML by hand, keep the page weight under a couple of hundred kilobytes, and hand over a repository you own outright. When the work is done you can edit the site yourself, from a laptop or a phone, without calling us.

  • Identity and typographic systems
  • Website design and hand-built front ends
  • Editorial structure and copy shaping
  • Ongoing small changes, usually the same week
